# Project Browser+ («Диспетчер проекта+») для Revit 2022

Диспетчер проекта на стероидах: отдельная dockable‑панель, которая живёт **рядом со стандартным диспетчером** (та же область, её можно перетаскивать, объединять во вкладки, отстыковывать), сохраняет весь привычный функционал и добавляет то, чего пользователям не хватает годами.

![build](https://github.com/wolfynys/-Project-Browser/actions/workflows/build.yml/badge.svg)

Разбор видео LUMOS, сравнение со стандартным диспетчером и список закрытых «болей» — в [docs/ANALYSIS.md](docs/ANALYSIS.md).

## Возможности

**Разделы (вкладки)**: Всё (как в стандартном диспетчере) · Виды · Листы · Спецификации · Легенды · Семейства · Группы · Связи · Уровни · Избранное и недавние.

**Навигация**
* Живой поиск, который фильтрует дерево (имя, номер листа, шаблон, уровень, категория; `id:123`; `*` — избранное).
* Группировки на выбор: как в Revit (организация диспетчера), по типу вида, уровню, шаблону, размещению на листах, дисциплине, стадии, масштабу, рабочему набору, префиксу имени, основной надписи, ревизии, дате выпуска, исполнителю…
* Быстрые фильтры: не на листах, без шаблона, открытые вкладки, зависимые, неиспользуемые семейства, пустые листы, проблемные связи…
* Сортировка: А→Я, Я→А, по номеру/значению, по Id. Естественная сортировка (2 перед 10).
* Бейджи в строке: масштаб, лист, число видов на листе, ревизия, количество экземпляров, «не используется».
* Подсветка активного вида, открытых вкладок; «Показать активный вид в дереве».
* Панель превью: типоразмеры — мгновенно, виды/легенды/листы — рендер по кнопке с кэшем.

**Операции (в контекстном меню, всё пакетно)**
* Открыть · Открыть лист с видом · Закрыть вкладки · Разместить экземпляр (двойной клик по типоразмеру, включая системные семейства).
* Переименовать (F2, прямо в строке; для листа `A-101 - Имя` меняет и номер) · Пакетное переименование (найти/заменить, regex, префикс/суффикс, нумерация, регистр) · Перенумерация листов (префикс, старт, шаг, цифр, суффикс, порядок).
* **Черновик**: правки накапливаются и применяются одной транзакцией кнопкой «Применить» (одно Undo в Revit).
* Дублировать (обычное / с деталями / зависимый, N копий) · Применить/снять шаблон вида · Удалить.
* Разместить легенды/спецификации/виды на выбранных листах (в той же позиции, что на образце) · Создать лист для каждого вида · Создать листы (пакетно, с основной надписью) · Создать планы по уровням.
* Семейства: выделить экземпляры (в виде / в проекте), показать и приблизить, редактировать, сохранить в папку, найти неиспользуемые.
* Связи: перезагрузить, выгрузить, открыть папку файла.
* Задать параметр для всего выделения · Копировать имена / Id · Экспорт списка в CSV.
* Избранное (Space), заметки, цветные метки — хранятся в `%AppData%\ProjectBrowserPlus`, модель не изменяется.

**Горячие клавиши**: Enter — открыть/разместить · F2 — переименовать · Del — удалить · Space — избранное · Ctrl+F — поиск · Ctrl+D — дублировать · Ctrl+A — выделить всё · Ctrl+C — копировать имена · ← → — свернуть/развернуть · Esc — сбросить поиск.

Интерфейс на русском (в настройках есть English). Иконки — [Lucide](https://lucide.dev) (ISC).

## Установка

Готовые файлы лежат в [`dist/`](dist/): `ProjectBrowserPlus.dll`, `ProjectBrowserPlus.pdb`, `ProjectBrowserPlus.addin`.

### Вариант A — обычная установка (рекомендуется, полноценная dockable‑панель)

1. Скопируйте `ProjectBrowserPlus.dll` и `ProjectBrowserPlus.addin` в
   `%AppData%\Autodesk\Revit\Addins\2022\`.
2. Запустите Revit 2022. На ленте появится вкладка **«Диспетчер+»** с кнопкой **«Диспетчер проекта+»**.
3. Кнопка показывает/скрывает панель. Панель регистрируется как вкладка позади стандартного «Диспетчера проекта» — её можно перетащить, объединить с другими панелями, отстыковать (стандартное поведение Revit).

### Вариант B — через Add-in Manager (без установки)

Add-in Manager умеет два режима:

* **Load Application** (вкладка *Loaded Applications*): загрузите `ProjectBrowserPlus.dll` и выберите `ProjectBrowserPlus.App` → выполнится `OnStartup`, панель зарегистрируется, появится вкладка на ленте. Это эквивалент варианта A.
* **Run Command** (вкладка *Loaded Commands*): загрузите DLL и запустите `ProjectBrowserPlus.Commands.ShowBrowserCommand`. Команда пытается зарегистрировать dockable‑панель «на лету». Revit рассчитывает на регистрацию панелей при старте и в некоторых сборках может отказать; тогда плагин **автоматически откроет ту же панель в плавающем окне** поверх Revit — весь функционал работает, только без стыковки. Для стыковки используйте Load Application или вариант A.

Также доступны команды `ProjectBrowserPlus.Commands.SettingsCommand` и `AboutCommand`.

> Add-in Manager загружает DLL из временной копии. Ресурсы WPF и иконки упакованы внутрь DLL, поэтому внешних файлов не требуется.

## Сборка из исходников

Требуется .NET SDK 8 (Visual Studio не обязательна). Ссылочные сборки Revit 2022 API берутся из NuGet (`Nice3point.Revit.Api.RevitAPI/RevitAPIUI 2022.1.80`), сам Revit для сборки не нужен.

```
dotnet build src/ProjectBrowserPlus/ProjectBrowserPlus.csproj -c Release
```

Результат: `src/ProjectBrowserPlus/bin/Release/net48/ProjectBrowserPlus.dll`. Скрипт `./build.sh` дополнительно копирует файлы в `dist/`. В репозитории есть GitHub Actions workflow (Windows), который собирает DLL и выкладывает артефакт.

На Linux/macOS .NET SDK из дистрибутива не содержит `Microsoft.NET.Sdk.WindowsDesktop`; достаточно скопировать эту папку из Microsoft‑сборки SDK в `<sdk>/Sdks/` — именно так собран `dist/` в этом репозитории.

## Как устроено

```
src/ProjectBrowserPlus
├── App.cs                 IExternalApplication: лента, регистрация панели, события
├── Commands.cs            ShowBrowserCommand (для Add-in Manager), Settings, About
├── Core/                  RevitTask (ExternalEvent-очередь), RevitEvents, PaneManager,
│                          Settings, Favorites (JSON в %AppData%), L (локализация ru/en)
├── Model/                 BrowserItem — строка дерева (без ссылок на объекты Revit)
├── Sections/              Построители вкладок: Views, Sheets, Schedules, Legends, Families,
│                          Groups, Links, Levels, Favorites, All + Grouper
├── Services/              RevitActions (все транзакции), PreviewService
├── UI/                    BrowserPane (XAML), BrowserViewModel, Icon (Lucide), Theme, диалоги
└── Resources/Ribbon       PNG-иконки ленты (генерируются из Lucide)
```

Принципы:
* панель модельная, поэтому любая работа с API идёт через одну `ExternalEvent`‑очередь (`RevitTask.Run`);
* дерево — плоский виртуализированный `ListBox` (тысячи строк, множественный выбор, поиск без тормозов);
* перестроение по `DocumentChanged` с задержкой 0.6 с, состояние раскрытия и выделение сохраняются;
* избранное/заметки/метки хранятся вне модели — безопасно для совместной работы;
* перенумерация листов делается в два прохода через временные номера, чтобы `A↔B` не конфликтовали.

`tools/gen_icons.py` превращает SVG Lucide в `UI/Icons.xaml` (геометрии) и PNG для ленты.

## Статус тестирования

Сборка проверена компилятором против Revit 2022 API. Прогон в живом Revit в этой среде выполнить было нельзя (нет Windows/Revit), поэтому первый запуск стоит сделать на тестовой модели; журнал ошибок пишется в `%AppData%\ProjectBrowserPlus\log.txt`, откуда его удобно прислать для исправлений.
